C++ Calculator 🧮

A simple command-line calculator built from scratch using C++.

This project was created as part of my journey learning C++ and focuses on practicing functions, input handling, calculations, arrays, and basic error handling.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⬛ Square a number
- 🔺 Cube a number
- 📊 Number statistics
- 📈 Calculate averages
- ⚠️ Basic invalid-input handling
- 🛡️ Division-by-zero protection

🛠️ Built With

- C++
- Standard C++ libraries
- Command-line interface

🚀 Getting Started

Clone the repository

git clone https://github.com/assassin-cloud/c-calculator.git
cd c-calculator

Compile

Using "g++":

g++ calculator.cpp -o calculator

Run

Linux/macOS:

./calculator

Windows:

calculator.exe
